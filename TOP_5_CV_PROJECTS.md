## Recommended order

These projects were selected based on technical depth, real-world business value, full-stack scope, architecture, and how effectively they demonstrate skills to a recruiter or hiring manager.

### 1. [Saro-Delivery](https://github.com/xobiya/Saro-Delivery)

**Why it belongs on the CV:** A strong production-style, full-stack delivery platform with multiple user roles and complex real-time workflows.

**Highlights:**
- Customer, vendor, driver, and admin dashboards
- Real-time order tracking and notifications with Socket.IO
- Interactive maps and driver navigation with Leaflet
- Chapa payment integration for the Ethiopian market
- JWT authentication, bcrypt password hashing, rate limiting, CORS, Helmet, and input validation
- REST API with Swagger documentation

**Technologies:** React, Vite, Node.js, Express, MongoDB, Mongoose, Socket.IO, JWT, Chapa, Leaflet, Swagger

**CV bullet:**
> Developed a full-stack delivery platform with role-based dashboards, real-time order and driver tracking, Chapa payments, interactive maps, and a documented Express REST API.

### 2. [Restaurant-Menu](https://github.com/xobiya/Restaurant-Menu)

**Why it belongs on the CV:** Demonstrates a complete restaurant operations product rather than only a UI prototype, including customer ordering, kitchen workflows, administration, payments, and deployment automation.

**Highlights:**
- QR/table-based ordering flow
- Live order tracking and kitchen status transitions
- Admin menu, order, payment, and table management
- Bilingual Amharic/English menu fields and ETB pricing
- JWT authentication with customer, kitchen, and admin roles
- Prisma/MySQL data layer and Socket.IO events
- CI/CD workflow with client builds and Prisma validation
- Deployment setup for Vercel and Railway

**Technologies:** React 19, Vite, Tailwind CSS, Zustand, Node.js, Express, Prisma, MySQL/MariaDB, JWT, Socket.IO, Chapa, Telebirr

**CV bullet:**
> Built a bilingual restaurant ordering and kitchen-management system with QR ordering, role-based administration, real-time order updates, Prisma/MySQL persistence, payment integrations, and CI/CD automation.

**Technologies:** React 19, TypeScript, Vite, Tailwind CSS, Node.js, Express, MySQL, Motion, Lucide React

**CV bullet:**
